# Official Software Development Process Pack

This directory is the canonical source of the production-grade software
development pack bundled with ProcessForge. It is distribution data, not part
of the domain-neutral runtime kernel.

It contains:

- stable software-development processes and agent prompts;
- bundled software/web knowledge-package declarations;
- a data-driven project classifier.

The pack is available by default but inactive until selected by the
`software-development` profile or explicit pack activation. The classifier and
declared capabilities must only participate in resolution while the pack is
active.
