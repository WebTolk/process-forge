# Canonical Work Selection — 2026-10-16

historical catalog after proving declared IDs, ownership, unique membership and
compatible processes through the existing Core validator. Four live reads retain
the final document boundary. Other queries and unsuccessful initial proof use
the existing catalog. Selected-read errors propagate; final failed proof returns
`work_identity_mismatch`. This deliberately corrects foreign alias precedence and
isolation from unrelated history errors. It is not universal old-behavior parity.

persistent index or cross-request cache was added. Context/access/intent checks,
transition locks, process pins and completion recovery remain in their owners.
