# Допуск к диагностическому журналу Windows, 16 октября 2026

Статус: исправление исходников независимо принято; коммит
`17206a1b335ea5d1c10ce374896cd2b3c729ffed`. Архив, установленное исполнение
и профиль Runtime фиксируются отдельно в
[отчёте dev-поставки](../releases/dev-journal-lock-20261016.md).

Исходный диагностический smoke не проходил проверку одновременной записи
процессами Windows даже при остановленном общем Runtime. Повторные наблюдения
обнаружили отказы допуска в пределах 50 мс. Интервал опроса 1 мс также давал
отказы и был отклонён. Лимиты и проверки не ослаблялись.

В Windows перед прежней байтовой блокировкой добавлен общий именованный mutex.
Единый срок включает блокировку потока, допуск, попытки байтовой блокировки
и ожидания; позднее получение отклоняется, захваченные ресурсы освобождаются
при любом отказе. Байтовая блокировка сохраняет исключение для старых/новых
писателей и алиасов пути. Имя mutex строится из нормализованного абсолютного
лексического пути без повторного открытия каталогов. Неузнанные junction/subst
алиасы по-прежнему опираются на байтовую блокировку. Очередь FIFO, равенство
между Windows-сессиями и отсутствие потерь при любых задержках I/O не заявляются.

Тела JSONL sink/logger, privacy, rotation, retention и quota сохранены.
Тридцать исходных контролей охватывают отказы API, потоки, алиасы, брошенный
mutex, пары новых и смешанных писателей; пересечения тел записи не обнаружено.
Пять пар новых писателей прошли без отказов; одна смешанная пара сохранила
одну допустимую потерю по таймауту. Этот результат не скрывался повтором
или увеличением лимита.

Последний полный исходный smoke прошёл без обвязки: 10 000 операций JSONL —
14,50288 с при прежнем лимите 20 с; memory sink — 0,4314/5 с; отключённое
логирование, 100 000 операций — 0,09427/0,5 с. Предыдущий вариант превысил
лимит JSONL: 20,8893423 с; отказ сохранён. Между вариантами из построения имени
mutex убрано дорогое разрешение реального пути. Инструментированные профили
1000 имён: 0,319318 и 0,0095543 с; это отдельные измерения, не обычный smoke.

Результат относится к исходникам и адресным проверкам. Установка и общий Runtime
требуют накопленной квалификации; фактический подключённый хост и полный
публичный релиз проверяются отдельно. Перед стабильной 1.2.0 нужны подробный
отчёт и отдельное одобрение пользователя.
