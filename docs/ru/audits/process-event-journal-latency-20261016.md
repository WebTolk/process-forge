# Задержка журнала событий, 16 октября 2026

Статус: исходники v5 независимо приняты после структурного исправления JR-02/JR-03. Архив, установленное исполнение,
CPU общего Runtime и фактический подключённый хост проверяются отдельно.
Ранее отклонённые варианты не дают допуска этому исходному коду.

Профиль настоящего допуска Work отнёс 9,839 инструментированной секунды к четырём
публикациям событий с повторным разбором истории JSON. Расчёт append/deduplication
теперь принадлежит конкретному Core-классу `ProcessEventJournal`. Прежняя обёртка
сохраняет подготовку вне преобразования registry SystemExit, ту же межпроцессную
блокировку и dispatch hooks после её освобождения. Байты записи, порядок раннего
дубликата, подавление только JSONDecodeError, flush/fsync и обязательные отказы
сохраняют прежние границы. CLI остаётся адаптером; общий переход на ООП не завершён.

Один ограниченный частный набор ID в памяти описывает точно разобранные байты.
Каждый append по-прежнему читает и хеширует все текущие байты под прежним guard;
должны совпасть digest, длина, канонический reader и допустимая текущая политика
разбора. Сохраняемые строки/структура набора ограничены 16 MiB. Дискового индекса,
TTL, доверия только к метаданным и пропуска текущего чтения нет. Холодная/изменённая
история, UUID fallback, неизвестный парсер, отказ необязательного выделения памяти
и превышение лимита сохраняют полный упорядоченный разбор.

В v5 любая подавленная JSONDecodeError запрещает индекс для этого содержимого.
Классы/конструкторы ошибок и дескрипторы не исследуются при импорте и не дают
основания для повторного использования. Ошибка разбора дописываемой записи также
запрещает публикацию индекса. Это сознательно уменьшает число попаданий ради
сохранения прежних отказов. Реальный корпус сравнения размером 101 379 731 байт
содержит 78 107 словарных записей и одну повреждённую строку; он всегда проходит
полный разбор. Его замер нельзя называть измерением прогретого индекса.

Предыдущие независимые проверки нашли отказ необязательного выделения (JR-01),
обход изменяемого поведения парсера/ошибки (JR-02) и отказ импорта при чтении
необязательных метаданных (JR-03). Все FAIL и прежние контрольные суммы сохранены.
Исходный smoke v5 прошёл без обвязки за 3,905492 с: четыре настоящих писателя,
same-size/mtime, внешний append/truncate/delete, байты/ошибки/fsync/hooks,
необязательная память, лимиты парсера, callbacks, дескриптор конструктора и alias
ошибки до импорта. Пятнадцать префиксов по пять запросов каждой версии дали
одинаковые байты. Ранее прошли transition-event и central-replay; финальные
проверки архива относятся к накопленной поставке. Проверки primary и независимый
review различаются; захват отчёта не выдаётся за READ_ACK.

Пять чередующихся последовательных пар по четыре события используют один корпус,
настоящие guard/fsync и dispatch=False, включая первый холодный запрос. Профайлера
и счётчиков внутри замера нет. Все хеши результата и исходников совпали.
