# Сервера обновлений для пакетов

Манифесты процессов, знаний, шаблонов, инструментов, платформенных контрактов,
отдельных process definitions и MCP могут объявлять `update_sites`. Для
публичного обновления, которое меняет поведение, указывайте `manifest_url` и
`changelog_url`.

У обновлений инструментов есть отдельная политика. В MVP проверен
воспроизводимый сценарий `replace_file`; `custom_command_requires_confirmation`
не исполняется автоматически и требует отдельного явного решения оператора.

Локальные переопределения хранятся в
`<workplace>/registries/update-site-overrides.yaml`. Через них можно отключить
сущность, заменить `manifest_url`, сменить `channel`, закрепить `pin_version`,
запретить major updates или оставить применение только ручным.
