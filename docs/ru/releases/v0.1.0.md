# Release v0.1.0

`v0.1.0` — первый file-first release ProcessForge.

В релиз входят:

- Python-first CLI;
- workplace initialization;
- project onboarding;
- agent start prompt;
- resource authoring for templates, knowledge packages and platform contracts;
- process authoring;
- run/task/iteration commands;
- authoring parity and backfill checks;
- release-test, release-pack и release-archive-test.

Не входят:

- GUI;
- marketplace;
- remote sync;
- database-backed control plane;
- mandatory long-running runner.

Проверка релиза:

```bash
python bin/pf.py release-test --root .
python bin/pf.py release-pack --root . --output dist/processforge-v0.1.0.zip
python bin/pf.py release-archive-test --archive dist/processforge-v0.1.0.zip
```
