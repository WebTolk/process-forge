# ProcessForge 1.3.0-alpha3

Накопительный альфа-релиз включает принятые изменения после alpha1, в том числе
из промежуточных dev-архивов alpha2, и добавляет обслуживание журналов SQLite.

Группа CLI `journal-maintenance` содержит команды backup, verify, restore,
inspect и import. Резервная копия создаётся через SQLite backup API, включает
подтверждённые данные WAL и сопровождается манифестом, хешами и проверкой
целостности. Восстановление создаёт новый файл и отказывается перезаписывать
существующий. Каждая база копируется отдельно.

Предварительная проверка выявляет повреждения старых журналов до импорта.
При применении сохраняются исходные журналы, а повреждённые строки помещаются
в карантин без изменения байтов, включая NUL. Фиксируются источник, номер
строки, смещение, длина и SHA256. Пропуск ошибок требует явного `--skip-invalid`.
Импорт сохраняет идентификаторы, дедупликацию и защиту от незавершённой миграции,
проверяет записанные данные и допускает повторный запуск. Существующий скрипт
`tools/migrate-hook-journals.py` остаётся доступным. Команды и порядок
восстановления описаны в [руководстве по обслуживанию](../concepts/sqlite-journal-maintenance.md).

Также включены исправления нативного ingress Kimi, календарный uptime в
мониторе, подсказки по evidence в ответах Work, рекомендательные замечания к
артефактам и общий учёт доступных данных о токенах и времени выполнения.
Неполное покрытие учёта явно отмечается, если провайдер или попытка не сообщает
все данные.

Обслуживание реализовано небольшими Core-сервисами с внедряемыми портами
операций и существующими владельцами журналов. Поддержка публичных контрактов
CLI/MCP и работы только с файлами сохраняется. Дальнейший рефакторинг Core
остаётся отдельной работой.

Это предварительный релиз в подключаемом канале alpha. Стабильная версия 1.2.0
остаётся доступной. Публикация сама по себе не обновляет установленный Core и
не перезагружает Runtime/MCP. Для установки используйте
[руководство](../getting-started/installation.md), сохраняя состояние и резервные
копии обновления.
