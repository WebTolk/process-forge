# ProcessForge 1.3.0-alpha1

Первая альфа фиксирует принятый этап разработки после 1.2.0. Публичные
контракты CLI/MCP и файловый режим сохранены. Версии продукта, процессов,
схем и startup contract остаются независимыми.

В выпуск вошли принятые изменения структуры Core, переносимые общие средства
Python QA и обязательные проверки качества, настройка нативных хуков Codex
при инициализации Forge, согласованная проверка контекста CLI/MCP при LF/CRLF,
проверенный запуск Windows App Server без консоли и обработка отключившихся
HTTP-клиентов. Выбор обновлений теперь различает предварительные и финальную
версии; build metadata не создаёт новую версию. Правила ограничений ресурсов
сохраняются.

Альфа публикуется отдельно от стабильной 1.2.0. Дальнейший рефакторинг Core,
полная проверка типов и систематическое покрытие модульными тестами остаются
будущими задачами. Публикация не обновляет устройство и не перезагружает Runtime/MCP.

Для отдельно запланированной установки используйте
[руководство по установке](../getting-started/installation.md) и
[порядок обновления Core](../concepts/core-update-manifest.md).
Сохраняйте состояние проектов и резервные копии обновления.
