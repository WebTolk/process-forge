# Частная dev-поставка: историческое наблюдение, 16 октября 2026

Принятые исходники: `63f1b9df4f715f3c719a3bda38f565ccd05bfdc1`. Архив, установка и фактический Runtime
квалифицируются далее в частной итерации версии 1.1.0. Публичный 1.2.0 не
опубликован: нужны подробный отчёт о готовности и отдельное одобрение.

Supervisor наблюдает согласованный завершённый захват как исторический факт,
без повторного полного сбора исходников и выходов каждый цикл. Явный collect,
первый захват и восстановление сохраняют полные текущие проверки. См.
[аудит исходников](../audits/supervisor-historical-observation-20261016.md)
и [контракт prepared input](../concepts/prepared-input.md).

Пять чередующихся пар на стенде четырёх реально захваченных управляемых попыток:
медиана supervisor 3,874953 → 0,521741 секунды, CPU 3,578125 → 0,421875.
Это не измерение установленного Runtime. Прежняя установленная версия занимала
95,066% одного ядра за 45 секунд и оставалась degraded. Чистый архив, одна
нативная установка по manifest, проверка конфигурации и истории, тихие исходные
проверки и бюджеты, обычный CLI/независимый stdio и реальное профилирование
Runtime/ОС проходят отдельно. Полные проверки 1.2, version/changelog/migration
и фактически подключённый Host остаются открытыми. Аудит smoke и политика
моделей лаунчера — отдельные будущие задачи.
