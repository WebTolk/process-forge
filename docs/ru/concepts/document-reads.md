# Повторное использование разбора YAML

Источником данных остаются YAML-файлы. Общий читатель PF открывает актуальный
файл перед выбором результата разбора. Совпадение размера или времени изменения
не доказывает неизменность содержимого: редактирование, замена и удаление видны
при следующем чтении. Этот механизм не кэширует разрешения, проверку капсул,
контрольные суммы исходных байтов и проверку допустимого пути.

Внутри работающего процесса результаты безопасного разбора используются между
запросами. Ключ включает SHA256 прочитанного текста и действующие правила
парсера, конструкторов и распознавания типов. Обработчики получают независимые
копии с сохранением YAML-алиасов внутри каждого результата. Ошибки разбора и
нестандартные конструкторы с возможными побочными эффектами не сохраняются в
общем кэше. Резервный разбор остаётся ответственностью существующего читателя.

LRU-кэш ограничен 4096 записями, оценкой в 64 МиБ для данных и ключей и 2 МиБ
на запись. Это предел удерживаемого кэша, а не памяти процесса или размера
входного файла. Большие и нестандартные структуры возвращаются без сохранения.
Парсинг и копирование не удерживают общую блокировку; одновременные первые
чтения могут разобрать один текст несколько раз.

Поиск запусков получает только `id`, `status` и существующий признак ошибки
после проверки всего входного документа. Кэш сохраняет эти поля, а не растущую
историю. Полное чтение по-прежнему возвращает полный документ. Первичный
разбор, чтение и хеширование актуального содержимого требуют работы; перенос
состояния Work из YAML в SQL этим изменением не выполняется.

Общий путь обслуживает читателей проектов, процессов, ресурсов, Work и метрик
Runtime. Строгий загрузчик конфигурации с её собственным обновлением, разовые
проверки архивов и обновлений и другие отдельные проверки сохраняют свои
контракты. JSON-состояние сессий и отложенной переписки Host остаётся отдельным
владельцем и этим механизмом не оптимизируется.

Технические источники: [Python copy](https://docs.python.org/3.14/library/copy.html),
[OrderedDict](https://docs.python.org/3.14/library/collections.html#ordereddict-objects),
[PyYAML](https://pyyaml.org/wiki/PyYAMLDocumentation).
