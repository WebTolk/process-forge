# События процесса

События проекта — приватная история в `.pf/runtime/events/events.sqlite3`. Они отражают решения, общение и технические события процесса, но доступность полной переписки зависит от захвата сообщений адаптером.

Сырые данные хука сохраняются отдельно в `.pf/runtime/agent-events/hooks.sqlite3` соответствующего проекта. Адаптер может создать нормализованное событие только после проверки привязки проекта. Неподдерживаемый хук или отклонённые данные могут не создать события проекта.

`chat.message.recorded` содержит хеш и ссылку на текст переписки; сам текст хранится владельцем стенограммы. Глобальные параметры `PFConfig.logging.raw_hooks` и `logging.events` независимо управляют двумя журналами; проект может переопределить их в `.pf/configuration.yaml`, а `null` означает наследование. Изменения применяются при следующем входящем событии без перезапуска.

Отключение истории сохраняет необходимые для работы ID, незавершённую обработку и последние факты проверки задач. Запись и поиск дублей используют индексы SQLite и не перечитывают историю. Старые NDJSON переносит временный `tools/migrate-hook-journals.py`; файлы сохраняются. Подробности — в [описании SQLite и миграции](../../concepts/hook-journal-sqlite.md) и [настройках](../../authoring/workplace-configuration.md#project-history-and-raw-hooks).
