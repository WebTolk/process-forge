# Классификаторы проектов

Классификация проекта управляется данными. ProcessForge собирает нейтральный
список путей, загружает активные classifier-документы из явных реестров,
проверяет универсальные условия `exists` и записывает полученные типы проекта,
платформы и теги. Если активного совпавшего классификатора нет, результат имеет
статус `unclassified`, а тип проекта равен `unknown`.

Classifier-документы соответствуют
`schemas/project-classifier.schema.json`, а реестры -
`schemas/project-classifier-registry.schema.json`. Правило содержит ровно один
непустой блок `all` или `any`; значения в `classify_as` являются непрозрачными
идентификаторами, смысл которых ядро не интерпретирует.

Инициализация рабочего места и onboarding проекта создают пустые реестры.
Оператор или установщик пакета должен явно импортировать классификатор и
добавить активную запись. Простое обнаружение пакета его не активирует.

Результат сохраняется в project-context snapshot и переносится в context
capsule. Изменение определения, реестра или marker-файла делает snapshot
устаревшим и требует refresh.
