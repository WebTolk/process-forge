# Готовность ProcessForge 1.2.0, 16 октября 2026

**Публичный релиз пока не готов.** Tag, assets и update channel не публикуются
до подробного отчёта и явного одобрения пользователя.

Установленный частный dev-источник: `a480bc55589c76186bf4ab2fa8dc4a3f478031fa`. [Отчёт о поставке](releases/dev-collect-journal-20261016.md)
фиксирует чистый архив, одну нативную установку, резервные прообразы,
сохранённую конфигурацию и историю, одно восстановление прежнего Runtime.
Исходники, архив, установленный Core, независимый stdio, фактический Runtime
и подключённый Host имеют отдельные границы доказательства.

Снимки журналов нескольких проектов и наблюдение устойчивого отказа collect
независимо приняты. Первый и явный collect, новые попытки сохраняют проверки;
временные ошибки повторяются. Отказ остаётся failed и видимым. Замечания
F01–F03 по identity и fingerprint исправлены; оба неуспешных ревью сохранены.

Прошли чистые schema/public/checksum, native archive quick, нужные исходные
проверки архива и установленной версии, doctors и оба неизменённых публичных
бюджета: task batch 53,73 с / 180 с, long-lived Runtime 55,05 с / 240 с.
Исходная диагностика **не прошла** параллельный Windows-допуск: пять отказов sink.
Проверка с сохранёнными данными воспроизвела таймаут бюджета 50 мс, пока сосед
держал критическую секцию 79 мс. Проверки и таймауты не ослаблялись.

Установленное чтение Work-state: медиана CLI 0.938278 с; независимый persistent
stdio 0.082300 с. Фактический Runtime занимает 84.199% одного ядра после
запуска и 90.207% в отдельном установившемся окне; health `degraded`.
Прежние установившиеся 87,949% относятся к другому моменту и backlog.
Общая скорость не принята. Повторный полный collect почти исчез из стеков;
основные текущие затраты — обход run, разбор YAML и публикация JSON состояния.
Перекрывающиеся стеки не являются долями CPU. Сравнение создания: {"github-v1.1.0": {"samples": 10, "median_wall_seconds": 2.4047379000112414, "median_cpu_seconds": 2.28125}, "installed-current": {"samples": 10, "median_wall_seconds": 0.4243662999942899, "median_cpu_seconds": 0.3671875}}; small fixture, Core.start only, same pre-seal scope adapter;v1.1 has a smaller original authority model. Not large-project CLI admission.

Для выпуска остаются общая производительность и полезный допуск большого
проекта, отказ диагностики, полные накопленные source/archive suites,
version/changelog/migration для 1.2.0, матрица интерпретаторов, фактически
подключённый Host и отдельное одобрение публикации. Исполнен CPython 3.14.3;
остальные версии этим срезом не квалифицированы. Work создаёт Core; стандартная
композиция ещё использует legacy-пути. Наличие классов не означает завершения
