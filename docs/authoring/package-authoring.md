# Package Authoring

A knowledge package is a versioned bundle of rules, references, templates, procedures, quality rubrics, and capability requirements.

Use packages for organization, direction, specialization, platform, toolchain, project, process, task, or agent-profile knowledge.

Required fields:

- `schema_version`
- `id`
- `name`
- `version`
- `kind`
- `scope`
- `description`
- `dependencies`
- `rules`
- `templates`
- `tools`
- `mcp_servers`
- `validation`
