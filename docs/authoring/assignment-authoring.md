# Assignment Authoring

Assignments bound one unit of work.

Required sections:

- id
- title
- role
- process id and version
- stage
- goal
- input artifacts
- allowed files
- forbidden files
- required outputs
- required artifacts
- required reviews
- allowed templates
- allowed tools
- quality checklist
- completion criteria
- log file
- handoff requirements
- status

Assignments should be small enough for one responsible writer.
