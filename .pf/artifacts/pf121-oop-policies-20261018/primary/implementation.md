# Реализация правил классификации и деклараций

Два переноса выполнены последовательно. `ProjectClassifierRulePolicy` и общий
`common.paths.path_matches_pattern` владеют существующим сопоставлением правил;
`ProcessArtifactDeclarationPolicy` владеет существующим расчётом defined/declared/
produced IDs. Обратных ссылок в монолит и новых зависимостей нет.

Один consumer writer обновил все вызовы в `tools/processforge.py` и удалил шесть
старых определений. Сохранены оба старых `as_list`, `string_list`, прочие пользователи
fnmatch и оставшаяся логика. Два stateless-экземпляра политик не удерживают Work
или mutable context. Точный состав — семь продуктовых путей из `brief.md`.

Core сообщил о девяти совпавших AST-фрагментах и 147 сравнениях поведения.
Все семь затронутых штатных smoke прошли за один запуск каждого; исходники
до и после совпали по хешам. Сборщик учёл описательные строки PASS трёх скриптов
по сохранённому выводу, без повторов и изменений тестов: `smoke-results.json`.

Документация EN/RU описывает реальное владение и оставшиеся legacy-обязанности.
В inventory изменены четыре строки и добавлены две, остальные 1313 сохранены.
Известные посторонние расхождения не исправлялись; глобальная проверка не запускалась.

независимое ревью, устранение блокирующих замечаний, отдельный коммит и push
