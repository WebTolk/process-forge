# Classifier и artifact policies — приёмка исходников

Результат: accepted_source_only, независимое ревью без блокирующих замечаний.
Baseline: `c75797d9a2d206c3ce5b3b6c5968fed092cbcd1e`.

Два переноса выполнены последовательно: `ProjectClassifierRulePolicy` с общим
matcher в `common.paths`, затем `ProcessArtifactDeclarationPolicy`. Все затронутые
вызовы переведены на Core, шесть прежних определений удалены из монолита. Сохранены
приоритет и short circuit all/any, платформенный fnmatch, scalar/list/dict semantics,
порядок str/truthiness и native errors. Обратных ссылок из новых владельцев нет.
Реестры, обход дерева, активация и полные валидаторы сохраняют прежних владельцев.

Состав: семь продуктовых файлов из `product-manifest.json`. Реализация описана
в `implementation.md`; сводные доказательства — в `verification.json`.
Core подтвердил девять AST-сравнений и 147 сравнений поведения. QA прошла 137/137
проверок, включая 109 сравнений поведения, 20 ожидаемых native exceptions и
изолированное использование исходного/скопированного Core. Семь затронутых штатных
smoke прошли по одному разу на тех же байтах исходников. Ревью подтвердило полноту
callers и отсутствие посторонних изменений в оставшихся 979 функциях монолита.

EN/RU карта владения обновлена. В inventory изменены четыре строки и добавлены
две; остальные 1313 сохранены. Три прежних посторонних расхождения не исправлялись
и повторно не валидировались. Две symlink-пробы штатного smoke были пропущены из-за
недоступности symlink; их успешность не заявляется.

Поставка: отдельный commit dev и push одного SHA в origin/dev и gitverse/dev с
полным readback; фактическая квитанция — `delivery/policies.json`. GitVerse использует
существующий токен через окружение процесса. Native lifecycle завершается штатными
переходами, рабочие записи после run_completed не переиспользуются.

Release notes: существующие правила теперь принадлежат Core, внешние CLI/MCP
контракты и версия 1.2.0 сохранены. Migration notes: схемы и данные не меняются,
внутренние callers переведены на канонические модули. Delivery/build profile:
not_applicable — source-only dev-рефакторинг на выпущенной основе 1.2.0, без нового
пакета или установки. Полный release suite, archive/install/Runtime/connected-host
qualification не входят в приёмку; ZIP-content проверки исключены пользователем.

После закрытия цикла перечитываются исходные архитектурные документы; следующие
обязанности выбираются по всей карте Core до 09:00 по времени устройства.
