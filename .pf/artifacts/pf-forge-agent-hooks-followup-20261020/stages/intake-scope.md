# intake-scope

Требование: при инициализации проекта на устройстве с эффективным режимом Forge автоматически настраивать поддерживаемые хуки агентов на PF. Базовая задача уже завершена для Codex. Эта регистрация добавляет только будущую задачу расширения списка агентов; перечень и версии согласуются при будущем проектировании. Запись разрешена только в карточку, общий draft Run/индекс и собственные артефакты. Код, текущие хуки, инфраструктура и замороженная alpha1 не меняются.

Результат относится к регистрации задачи; выполнение продукта не подтверждается и не запускается.
