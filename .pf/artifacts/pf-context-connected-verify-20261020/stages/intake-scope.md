# Границы проверки MCP/CLI

brief: после однократной установки context fix старый подключённый MCP ещё
возвращал stale/ask_operator. Пользователь перезапустил сессию и поручил узкую
приёмку. Нужен настоящий ответ текущего соединения на прежнем снимке.

scope: только доказательства контекста, provenance, exact Work и разрешения
ресурсов; сопоставление с двумя CLI и историческими fresh/stale сценариями
принятого source fix. Запрещены refresh, update, restart, исходные исправления,
проверка ZIP и продолжение OOP. Сбор фактов не требует управлять службами.

task-record: исходная карточка pf-cli-mcp-context-consistency-20261019 будет
завершена только native task-complete после подтверждения критериев. Остальные
карточки и состояние очереди сохраняются. Новая проверка не возобновляет
завершённые source/delivery Work.

scope-accepted: список разрешённых файлов и единственный владелец подтверждены
по exact state и capsule. Граница трёх задач зафиксирована в orchestration.md.

Handoff: investigation сохранит live ответы MCP, CLI, process ancestry и hashes.
