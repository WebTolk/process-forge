failed before startup because the native driver requires an explicit configured
model; attempt2 inherited the existing local Codex model gpt-6.1-sol. Actual
executors then correctly reported missing workplace knowledge/tool grants and
orchestration-stage prepared input. Their reports and attempts are preserved.

The MCP Work scope creation surface cannot declare workspace_access grants.
Use the existing native task-create CLI to admit four implementation-stage
contributions inside the already designed parent Run, with exact disjoint scopes,
explicit workspace knowledge and tool grants and a new immutable capsule each.
Do not edit/rebuild old capsules or reuse cancelled Work. Parent coordinates the
child lifecycle from accepted design through contribution completion.

Executor instructions: implement only the frozen assigned component and tests;
do not execute PF lifecycle commands or self-register sessions. The primary owns
Ledger registration, stage transitions and coordination actions. Emit an explicit
READ_ACK after actually reading the frozen sources, and RESULT after code/QA,
as normal agent progress messages; native worker ingress records these real
messages under its attempt identity. Primary forwards their immutable references
through PF chat. A recorded capture alone is not a READ_ACK.

typing/dataclasses/pathlib/PEP8/257/Protocol material and registered QA commands.
Read prepared scope fields selectively; do not dump full capsules or scan history.

when feasible; final report can complete the native attempt without claiming the
parent task/release complete. No independent Git, infrastructure or device action.
