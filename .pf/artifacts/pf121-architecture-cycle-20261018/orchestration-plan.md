# План архитектурного цикла после 1.2.0

Статус: исследовательский результат готов; выполняются native closure и доставка прежнего Work после прерывания основного агента.

Результат этого Work — сопоставленный аудит архитектуры, доменные ограничения и проверяемый план следующих небольших срезов. Исследование не разрешает изменять продукт: для реализации выбирается новая ограниченная Work с исходными архитектурными документами в required_sources.

| Шаг | Ответственный | Область записи | Состояние |
| --- | --- | --- | --- |

| Проверить карту действующей архитектуры и предложить три среза | topology-worker | `.pf/artifacts/pf121-oop-topology-20261018/`, одноимённый scratch | Attempt 1 completed/exit 0, collected, выводы сопоставлены |

У всех четырёх native shell-воркеров сохраняется прежний `gpt-6.1-sol`, `ultra`; вложенные агенты запрещены их капсулами. Основной агент не подменяет независимое ревью реализации исследовательскими отчётами. В этой волне реализации нет, поэтому ревьювер реализации ещё не запускается.

Контрольные условия: один writer в каждой области; сохранение CLI/MCP-контрактов, ошибок, форматов и порядка проверок; явное различение текущего кода и предложений. Не добавлять обязательные зависимости, мастер, ресурсы MCP, метрики памяти или изменение политики логирования внутри рефакторинга.

Доставка: отдельные коммиты четырёх исследовательских вкладов и интегрированного результата; после каждого одинаковый SHA обеих веток dev согласно `.pf/AGENTS.md`. В коммит включать только файлы этой логической задачи; прежнее dirty/staged состояние сохранять. Public release, stable metadata, установка и инфраструктура не входят в эту доставку.

Оставшиеся внешние границы: source/installed MCP mismatch сохранён в журнале; GitVerse PR1 open/merged:false не исправляется данным циклом. Прежние отказы удаления concepts/audit и записи служебного checkpoint не обходятся.
