# Воркер 2: готовые библиотеки и простые механизмы

Прочитай общий team-brief и знания Python из PF. По текущему коду выясни, какие
задачи решают собственные логгеры, измерение памяти и внутренние OOP-механизмы.
Сопоставь существующие решения со стандартной библиотекой и распространёнными
прикладными библиотеками. Сначала локальные разрешённые источники, затем при
необходимости актуальные официальные документы проектов; указывай ссылки.

Нужна краткая таблица: фактическая потребность PF, существующий механизм,
подходящая стандартная/внешняя библиотека, выгода, зависимости и цена внедрения,
совместимость с файловым режимом, Windows/POSIX и автономной установкой, решение
«применить сейчас / исследовать позже / оставить существующее» с аргументами.
Рассмотри stdlib logging, разумность psutil для памяти и альтернативы, обычную
композицию/Protocol/dataclass вместо самодельных контейнеров. Не считай добавление
пакета улучшением само по себе; не меняй зависимости и не устанавливай их.

Только исследование кода и документации, без продуктовых правок, полных тестов,
инфраструктуры, внешних записей и вложенных агентов. Пиши только
`.pf/artifacts/pf121-oop-libraries-20261018/report.md` и собственный
`.pf/tmp/pf121-oop-libraries-20261018/`. Разделяй текущие факты, проверенные сведения
о библиотеках и предложения. Основной агент принимает итоговое решение.
