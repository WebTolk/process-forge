# Воркер 3: установка и обновление

Прочитай общий team-brief и знания Python из PF. Исследуй реальные точки входа,
скрипты, команды, тесты и документацию установки/обновления. Ничего не устанавливай,
не применяй к устройству, не меняй службы, настройки машины или ACL. При необходимости
используй только help/read-only и небольшие изолированные проверки в собственном tmp.

Опиши текущие пути пользователя и проблемы ясности. Предложи простой пошаговый
мастер: выбор рабочего места/путей, важные параметры, понятные пояснения, проверка
ввода, предварительный итог и явное подтверждение действий. Раздели интерактивный
режим и существующий неинтерактивный CLI так, чтобы не сломать автоматизацию.
Объясни, где уже есть подходящие функции и где нужен небольшой OOP-адаптер.
Для обновления учитывай резервное копирование, отдельную миграцию истории и
существующее требование confirm; не обещай отсутствующие rollback/автоматическую
миграцию. Укажи предлагаемые файлы, зависимости и проверки, не реализуя их сейчас.

Пиши только `.pf/artifacts/pf121-oop-installation-20261018/report.md` и собственный
`.pf/tmp/pf121-oop-installation-20261018/`. Отчёт на русском, факты с путями/символами,
проект шагов мастера, варианты реализации и ограничения. Без вложенных агентов,
полных релизных прогонов и внешних записей.
