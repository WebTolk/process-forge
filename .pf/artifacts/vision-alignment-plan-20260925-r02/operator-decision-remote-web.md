# Уточнение оператора: удалённый веб — позднее

- date: 2026-09-25
- type: operator-scope-clarification
- source: текущее сообщение оператора
- scope: направление и сроки веб-интерфейса; не разрешение реализации

> Ок. Веб у нас будет удалённый далеко потом.

Подтверждённая граница для дальнейшего планирования T10:

- Ближайший интерфейс — локальный терминальный монитор существующего pf-server.
- Локальная браузерная панель не включается в план.
- Будущий веб-интерфейс будет удалённым и относится к дальней перспективе.
  Сейчас не проектировать и не реализовывать его frontend, удалённый доступ,
  сетевую публикацию, аутентификацию или развёртывание.
- Это не запрещает существующий локальный IPC/HTTP транспорт Runtime:
  транспорт сервиса и браузерный интерфейс — разные понятия.
- Локальный сервер/монитор не должен требовать будущего удалённого веба.

Это уточнение заменяет только вариант локальной web-панели в
[предложении T10](pf-server-proposal.md). Остальные детали предложения не
получают автоматического утверждения. Закрытый Run, его evidence и предыдущие
документы сохраняются неизменными; новая реализационная Work не запускалась.
