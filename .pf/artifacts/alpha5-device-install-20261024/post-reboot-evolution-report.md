# Наблюдения завершённой приёмки alpha5

Операторская перезагрузка устранила прежние внешние process boundaries.
Подтверждать это следует фактическими процессами, serving provenance и
authenticated status; повторная установка для этой проверки не требуется.

Initial degraded и следующий ready результаты сохраняются раздельно. Успех
doctor с warning и совпадение build не заменяют успешный authenticated ready
status с живым scheduler. В этой приёмке такой ответ получен без изменения
таймаута, guard или бюджета. Причина первого degraded не установлена.

Derived project-context search stale/coverage 5 из 7 и complete Work material
7 из 7 — разные наблюдения. Runtime session/work/worker totals остаются unknown
при partial coverage. Новые global maintenance или продуктовые задачи здесь
не запускаются. Для изменения их состояния нужна отдельная ограниченная Work.

Конфигурация, главный Git index, индекс поиска и чужие файлы сохранены.
Старые handoff/decision/report остаются историей; successor decision явно
указывает закрытые actual process gates. Новые глобальные правила, память,
process definitions и immutable capsules не изменены.
