# T10 first slice: scope and acceptance

Результат: рабочая CLI команда `pf monitor --workplace ...`, read-only терминальное окно существующего Runtime. При перенаправленном выводе — один plain snapshot; `--json` — один JSON без ANSI. `--once`, `--interval`, `--ascii`, `--no-color` позволяют предсказуемую эксплуатацию. Выход q/Esc/Ctrl+C закрывает viewer, не управляет daemon.

R01: общий lifecycle трактуется по lock/state/PID/готовности; orphaned/stale/unknown не становятся ready. R02: отдельно readiness, сохранённое health/scheduler и freshness; malformed/missing/future timestamps видны. R03: использовать только ограниченные чтения известных state files и bounded loopback readiness probe, без project-tree scans, token creation, writes, start/restart/tick. R04: зарегистрированные projects/session cache не называются active; live workers/leases/work/event rates/MCP/hooks без источника unknown. R05: корректная перерисовка широкого/узкого/низкого/изменяющегося терминала, Unicode/ASCII, очистка остатков строк, восстановление cursor/terminal после выхода. R06: stdout JSON/non-TTY чистый, raw exceptions/logs/prompt/token/path map не выводятся; строки защищены от terminal injection. R07: CLI проверяет конечные интервалы и flags; явные exit codes; EN/RU docs и meaningful tests.

Точный file scope — orchestration.md. Срез не выполняет все будущие пункты T10: отдельный pf-server executable/tray/lifecycle controls, log-profile editing и новые authoritative metrics contracts не включены. Непокрытые показатели явно отображаются как unknown; их нельзя имитировать счётчиками исторических registrations. Нынешний proposal остаётся исходным неизменённым документом, в handoff фиксируется принят только первый срез.

Acceptance: source smoke с реальными subprocess CLI и fake loopback server; проверка неизменности filesystem/daemon при выходе; экранная state regression и resize; failure-path/size/time limits; existing lifecycle regressions; schema/public-cleanliness/checksum checks; live read-only source command against existing installed state. Installation/public release/browser not_applicable. Не заявлять установленную поддержку новой CLI до отдельного update.
