hashes are retained in architecture-reread.json. The full ADR/domain/direction,
the clarification, progressive boundary and current migration contract take
precedence over provisional earlier class names and legacy bridge exceptions.

R01-R05: exact identities and current scope/action checks remain at their existing
owners. Neither moved helpers nor dependency construction widen permissions.
R06: registry, parameter and assignment document reads remain live; existing
same-metadata/read-isolation cases pass. R07: failure order, controlled exception
identity and completion/transaction recovery remain compatible. R08-R09: trusted
ingress and execution-coordination roles are unchanged. R10: all writers have
disjoint native scopes; historical approved artifacts and capsules are preserved.
R11: deliberate shell retry creates attempt2 within the same Work; the failed
first attempt is not rewritten. R12: public delivery records use relative source
paths and provider identifiers, without private resolved roots or credentials.

Concrete Python material: the PF-selected project digest of locally read PEP20,
PEP8 import/naming/interface sections and descriptor method binding. This is not
a claim to have read complete external manuals through metadata-only grants.

One native intake transition reported journal_database_error after its durable
stage advancement. Exact readback showed investigation with valid context and
ready execution; subsequent native transitions succeeded. The failed receipt
is retained, the completed stage was not blindly repeated, and no infrastructure
repair or general journal-health acceptance is claimed.

Normal concrete Core construction is covered by the worker proofs; affected
existing checks cover final source behavior. This document does not itself close
independent review, remote delivery or the wider OOP epics.
