# Shared parse reuse implementation plan

Add a single YamlParseCache owner in documents/parse_cache.py. Use stdlib OrderedDict/RLock/deepcopy, content SHA256 (chunked UTF-8 surrogatepass hashing), safe-loader/parser/constructor/resolver fingerprint and optional selected fields as the key. Keep64MiB estimated retained graph/key budget,4096 entries and2MiB per retained entry; reject custom value graphs, oversized snapshots and parse errors. A large input may still cache a small projection. Lock only cache/counter/accounting operations, parse/copy outside it. No source reads inside the cache and no filesystem writes.

common.request_scope.safe_load keeps its call signature and safe-loader selection; route request misses/unscoped calls through the shared owner. Existing request cache stays; count actual parses and all reuse in existing parses/hits diagnostics fields. Add internal safe_load_fields for small validated projections. Include current policy in request identity too, so loader rule changes do not reuse an old local result.

YamlDocumentReader keeps its frozen fallback-only constructor and existing load/read/fallback/error/read-failure behavior. Add load_fields, reusing identical fresh file reading and error handling. active_run_ids requests id/status/__yaml_error__ directly; other authoritative consumers continue full reads. Runtime metrics uses the same safe_load only after all current read/budget/identity checks. No blanket switch of distinct custom loaders or unrelated validation boundaries.

Assurance after implementation: existing request-scope tests adapted for cross-request reuse; meaningful new tests for same-size/restored-time edits, deletion/recreation, safe/unsafe/invalid YAML, policy changes, aliases/cycles/mutation, nested and concurrent reads, entry/memory eviction and large history projections; exact frozen-corpus before/after active IDs and cold/warm CPU/parse counts; existing Work/Runtime/metrics/security checks relevant to the shared owner. Inspect error and fallback parity, no stale file or authority cache. Review source and bounded memory, then checksum in isolated source.

Delivery: commit/push scoped source/records to both dev remotes; build clean qualified dev archive at that new SHA, native plan/apply/backups/status without replaying SQLite import; managed Runtime stop/start and actual owner/source/ready verification;60-second CPU and current external stack sample.
