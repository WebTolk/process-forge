# Исправление повторного разбора YAML в PF

Исправление установлено и проверено на работающем Runtime. Общий читатель повторно использует результат безопасного разбора неизменившегося YAML в оперативной памяти процесса. Поиск активных Run получает только проверенные поля состояния, без копирования всей истории. Текущие файлы по-прежнему читаются; полный обход каталога не устранён.

На замороженном наборе 570 файлов результат сохранился: 49 активных ID в прежнем порядке. Проход установленного кода после прогрева занял 0,141 секунды CPU против прежних 3,44–4,55 секунды. Это проверка каталога, отдельно от измерения службы.

Минутный замер Runtime на четырёх логических процессорах: **15,44% CPU**, прежде **18,59%**. В последующем профиле за 30 секунд получены 1280 выборок без ошибок. Доля поиска Run снизилась с 49,55% до 3,44%; нативный разбор YAML в выборках не встретился. Основной оставшийся потребитель — чтение и запись Host JSON: 76,56% выборок, файл 37,8 МБ. Общая фоновая нагрузка остаётся существенной.

Кэш общий для проектов внутри одного процесса PF, без файлов на диске. Лимиты: 4096 записей, 64 МиБ по оценке удерживаемых данных и ключей, 2 МиБ на запись. При заполнении LRU вытесняет старые записи, при завершении процесса память освобождается. У отдельных процессов свои экземпляры; точный расход RSS и временные копии этими лимитами не задаются. На контрольном наборе оценка кэша составила 12,1 МБ; фактическое заполнение кэша службы отдельно не измерялось. Пользователь уточнил устройство кэша и подтвердил продолжение.

Проверки: 14 применимых smoke-программ, синтаксис, схемы, чистота публичного состава, контрольные суммы, короткая проверка распакованного dev-архива и сверка установленных файлов прошли. Одна необязательная проверка со старым извлечённым эталоном явно пропущена. Исходный коммит `8f00ca1711f1d7ad276da61a9fcbec907da0cd36` опубликован в обеих ветках `dev`; установлен штатным обновлением `core-update-20261017T074204Z`. После обновления запущен Runtime PID `18280`, instance `e6906e3fd2a74ffdba75b60cae8df1b7`.
