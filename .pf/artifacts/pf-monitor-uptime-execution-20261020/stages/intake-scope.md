# intake-scope

Показывать existing uptime в формате годы/месяцы/дни/часы/минуты, не менее двух цифр на поле, без секунд. Сохранить числовое uptime_seconds, публичный JSON/CLI/MCP, read-only наблюдение, screen resizing и поведение сервера. Неизвестные/невалидные входы остаются unknown. Месяцы и годы считаются по заранее записанному календарному правилу UTC, без условных констант.
