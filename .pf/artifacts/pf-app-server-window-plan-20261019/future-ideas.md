# Идеи для следующих задач монитора

Status: captured_future_idea
Date: 2026-10-19
Source: прямое уточнение пользователя в этой сессии

Позднее в монитор можно добавить **список проектов с просмотром подробностей
по каждому проекту**. Пока это затравка для будущего развития, а не требование
нынешнего интерфейса и не поручение начинать реализацию.

При отдельном планировании определить доступные данные, выбор проекта,
read-only детали, актуальность сведений и границы доступа. Использовать
существующие регистрации и проверяемые источники; не вводить неограниченный
обход диска ради заполнения списка.

Здесь не созданы новая продуктовая задача, расписание или worker. Идея
сохраняется вместе с планом; при последующем явном поручении связать её
с соответствующим backlog без дублирования.
