Статус: ready_for_review.

Адаптер проверяет TTY, локальную среду, видимость и класс console HWND,
неизменность привязки и список клиентов консоли. Допускается ровно один клиент,
PID текущего процесса. Windows Terminal, SSH, ConPTY, чужие и общие консоли
не получают запрос минимизации. Native API связывается только при вызове.

Для собственного окна вызывается ShowWindowAsync(SW_MINIMIZE). Возврат запроса
не считается успехом: результат minimized требует наблюдаемого IsIconic.
После запроса выполняется до шести наблюдений с повторной проверкой владения;
суммарные ожидания ограничены 250 мс. Ошибки и неподдерживаемые среды возвращают
оговорённые статусы и не меняют жизненный цикл сервера.

Профиль Task Scheduler формирует действие с неизменным явно переданным Python:
tools/processforge.py runtime serve --minimized и прежними workplace/port/interval.
Прямой CLI принят primary: Windows-launcher bin/pf.py оставляет дополнительного
клиента консоли и нарушает условие единственного владельца. Процесс остаётся
сервером в текущем окне без отсоединяющей обёртки; настройки XML не менялись.
Существующий старый профиль корректно определяется как drifted. Реальные задачи
не читались и не изменялись; применение миграции остаётся отдельным действием
оператора.

25 изолированных проверок прошли. Нативная поверхность предоставила невидимый
неклассический HWND; корректный отказ подтверждён, минимизация видимого
классического окна остаётся отдельной непроведённой приёмкой. Подробности и
границы доказательств приведены в verification.md.
