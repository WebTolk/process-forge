# Отчёт: документация окна PF App Server

Дата: 2026-10-19  
Исполнитель: `pf-app-server-window-docs`, попытка 2  
Статус: `ready_for_review`

Обновлены шесть разрешённых файлов:

- `docs/getting-started/installation.md`
- `docs/getting-started/runtime-autostart.md`
- `docs/concepts/runtime-monitor.md`
- `docs/ru/getting-started/installation.md`
- `docs/ru/getting-started/runtime-autostart.md`
- `docs/ru/concepts/runtime-monitor.md`

В обеих локализациях описаны автоматический TTY-заголовок с логотипом PF, версией работающего Core и PID, необязательный `--console` и явный запрос `--minimized`. Уточнено, что заголовок не подтверждает готовность сервера.

Основной пример сворачивания использует прямой вход `tools/processforge.py`. Объяснены ограничение дополнительных процессов запуска в Windows, отдельная классическая консоль, отказ для Windows Terminal/ConPTY и общих окон. Для Linux указан узкий механизм локального X11 через прямой `xterm -e`, установленные `xprop`/`xdotool` и проверки принадлежности окна. Отдельно описаны ограничения Wayland/XWayland, SSH, мультиплексоров и работы без графической среды.

Разграничены свёрнутое окно, оконный запуск без консоли через `pythonw.exe` и фоновый `runtime start`. Документированы прямой запуск Task Scheduler с `--minimized`, сохранение указанного Python и операторская замена прежнего профиля через предварительный просмотр и `--replace --apply`.

Существующий монитор остаётся отдельным процессом только для чтения. Textual и `autostart_pf_app_server_monitor` явно обозначены как будущие возможности и отсутствуют в исполняемых примерах.

- Проверка справки CLI для описанных точек входа, псевдонимов и параметров.
- UTF-8, баланс блоков кода, 30 относительных ссылок и якорей.
