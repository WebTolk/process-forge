# Governed final evidence delivery

The aggregate and its seven current contribution/review Works retain their exact
scopes until actual code review, source/archive qualification, dual-provider
alpha4 publication and metadata commit/push are complete. Historical canceled
reservations remain canceled; no terminal Work is resumed.

After those eight product Works reach run_completed, start one fresh bounded
primary release-finalization Work for portable evidence and Git delivery only.
Its write scope is this primary artifact directory, primary log and existing
primary scratch; no product source, feed, historical archive, installed device
or infrastructure changes. It may read the completed native state and receipts.
Required immutable inputs are this plan and the actual release-readiness and
metadata-delivery receipts. This avoids writing through a terminal product Work.

Within that fresh scope, export only portable evidence: preserve exact raw
receipts/worker reports/capsules locally, reject private paths/credentials,
record immutable source hashes and explain normalized derived copies. Commit
the curated product closeout after its actual native completion, push the same
commit to origin/dev and gitverse/dev in parallel, read back both exact SHAs and
retain the receipt. Run the finalization's own scope/capsule checks and complete
its native stages using that actual delivery evidence. Its final native event
remains in PF state; no self-referential evidence-commit loop is required.

The release tag remains on the fully qualified source commit. Metadata and final
evidence commits are separate, contain no product correction and cannot replace
source/archive/actual-host proof. Actual installed/connected-host acceptance is
not claimed. After final readback and run completion, stop and report to the user.
