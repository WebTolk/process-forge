# Scope and lifecycle decision

One cohesive delivered result: project refresh observes existing search readiness;
workplace maintenance owns indexing independently through explicit manual operation
and the existing Runtime scheduler. Retain published CLI/MCP parameters and payloads,
context-required resource checks, query-time project/Work access intersections,
file-only operation, existing index locks and crash recovery. No general health
framework, new database backend, device update or whole-Core rewrite.

Execution is implementation with review; mandatory assurance and release delivery
apply. Primary has a valid immutable capsule; exact read/write scope verified.
Native worker ownership is fixed in architecture before launch and remains disjoint.
Primary owns external registered QA and lifecycle/chat; file-only workers consume
actual frozen PF-selected Python excerpts. Reviewer never writes product code.
