# План shell-воркеров: подготовка исправления audit findings

Дата: 2026-08-14

## Цель

Подготовить один реализационный план для двух подтверждённых дефектов, не смешивая
их с условными policy-наблюдениями и не изменяя продуктовый код в плановом run.

## Изолированные поручения

1. `plan-concurrency-start-guard` — только запуск одной worker-задачи и durable state.
2. `plan-driver-provenance` — только сохранение и повторное разрешение ad-hoc driver.
3. `plan-regression-interface` — только место и дизайн регрессий, плюс судьба
   низкоприоритетных наблюдений.

Каждому worker-у принадлежит лишь его отчёт; пересекающихся product-write scope нет.
После завершения orchestrator проверит capsules, exit state, отчёты и их выводы,
после чего соберёт единый plan и выполнит финальный review.
