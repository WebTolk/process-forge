# domain-modeling

Постановка различает HTTP-транспорт, повторяющуюся обвязку авторизации/JSON/таймаутов, предметную обработку и предоставление операции через MCP. Решение должно опираться на реальные сценарии и может заключаться в повторном использовании существующего средства; временные сценарии не объявляются ошибкой по умолчанию.
