# Окно обслуживания Runtime

Штатный `server stop` без `--force` отклонён с кодом 1 и ответом
`409 runtime_busy_or_activity_unknown`. Установка пока не изменена.

Дополнительное наблюдение через существующий модуль PF, без изменения его
кода и параметров работающего сервера, установило:

- обычная проверка workers: partial, причина budget, точное число неизвестно;
- полная отдельная проверка двух зарегистрированных проектов: complete,
  running=0, без ошибок и непокрытых проектов;
- просмотрены 333 файла и 4597 записей каталогов за 0,89 секунды;
- штатный ограничитель допускает 128 файлов, 512 записей каталогов и
  0,5 секунды на проверку для остановки.

Неполную штатную статистику нельзя выдавать за доказательство отсутствия
работы. Полная проверка workers также не доказывает отсутствие выполняющегося
HTTP-запроса или прохода планировщика в момент будущей остановки.

Пользователю предложено явно разрешить каноническую остановку `server stop
--force`, которая обходит проверку занятости. Принудительное завершение
процессов и остановка MCP-хоста не входят в действие. До ответа зависимые
изменения устройства не выполняются. Сырые результаты сохранены приватно.
