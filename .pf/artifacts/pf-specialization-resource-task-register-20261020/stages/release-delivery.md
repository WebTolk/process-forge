# release-delivery

Публичный релиз, установка и инфраструктурные действия к этой регистрации неприменимы. Подготовлена отдельная доставка только собственных артефактов в origin/dev и token-backed gitverse/dev с точным readback, сохраняя чужие dirty/staged изменения. Окончательная Git-квитанция сохраняется приватно. Замороженная alpha1 остаётся прежней.

См. ../report.md, ../registration-checks.json и ../native-checks.json.
