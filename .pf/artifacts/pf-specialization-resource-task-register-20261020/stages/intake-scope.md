# intake-scope

Главное требование: исследовать случай, когда одного наличия пакета в специализации недостаточно для доступа к содержимому и нужен явный выбор конкретного ресурса в проектном контексте. Точный ресурс joomla.rest-api.documentation:rest-api-docs. Задача дальнего горизонта, без срока/релиза. Прикладные REST-поля и подтверждение публикации сохраняются как контекст примера; разработки REST сейчас нет.
