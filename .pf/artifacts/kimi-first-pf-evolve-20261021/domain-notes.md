# Domain Notes

## Core concepts
- New agent onboarding: опыт первого контакта с PF.
- Usability gap: разрыв между ожиданием и реальностью инструментов.
- Automation opportunity: действия, которые могут быть автоматизированы для агента.

## Actors
- Kimi agent: новый участник, впервые работающий с PF.
- ProcessForge: система управления процессами и артефактами.
- Operator: пользователь, направляющий работу.

## Rules
- Новый агент должен тратить время на задачу, а не на борьбу с инструментарием.
- Ошибки должны содержать actionable remediation.
- Сессия и хуки должны работать "из коробки" при корректной настройке host.
