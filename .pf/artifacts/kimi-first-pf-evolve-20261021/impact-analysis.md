# Impact Analysis

## Влияние на новых агентов
- Высокий порог входа замедляет адаптацию.
- Много ошибок на старте из-за неявных требований (scope, evidence format, gate statuses).
- Ручная регистрация сессии создает разрыв между ожиданием (hook должен был сработать) и реальностью.

## Влияние на продуктивность
- ~30% времени тратится на борьбу с инструментарием вместо решения задачи.
- Необходимость читать исходный код PF для понимания ошибок снижает автономность.

## Приоритеты улучшений
1. Автоматическая регистрация сессии при SessionStart (или явная инструкция).
2. Quick-start режим для assurance/evolve-only работ (минимум стадий).
3. Улучшенные сообщения об ошибках с примерами исправления.
4. Генерация шаблонов артефактов и evidence.
5. Команда для безопасного просмотра больших директорий (outbox).
