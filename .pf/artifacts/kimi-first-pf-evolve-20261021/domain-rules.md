# Domain Rules

## R1. First-run experience must be measurable
Every new agent session should produce structured feedback on onboarding friction.

## R2. Errors must be actionable
Error messages should include what is wrong and how to fix it, not only a code.

## R3. Session lifecycle should be automatic
Agent check-in and heartbeat should not require manual intervention when host hooks are configured.

## R4. Simple tasks need simple flows
Assurance/evolve-only work should not require full 8-stage lifecycle.
