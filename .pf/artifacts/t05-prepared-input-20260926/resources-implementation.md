# T05 Prepared Resource Authorization Handoff

Role: implementation, bounded to `src/processforge_core/prepared_resources.py`.

Implemented `authorize_resources(project, task, capsule, core)`. The caller remains responsible for validating the execution contract. This service normalizes and cross-checks requested workspace access against the task and pinned contract, requires a fresh current project snapshot, verifies the historical snapshot bytes against the capsule/contract pin (or requires the current snapshot to match when the generation file is absent), and rejects missing or ambiguous pinned/current resource matches.

Knowledge grants require a unique match in capsule and pinned snapshot resources, selected-ID membership, and the pinned process stage subset when the task has a stage. The service requires a version-1 available T02 binding, a currently available resource row, matching metadata fingerprint/generation/material fingerprint/kind/manifest, and bounded T02 material capture. It never returns fulltext bodies. Fulltext grants include private resolution paths; metadata or no-material grants use `resolution.status: metadata_only` without a root path. Templates, tools, and MCP grants require exact pinned/current resolved-row equality and successful path-reference resolution. Empty requests produce empty grant arrays. Failures raise stable-code `ValueError`s for the caller to block preparation.
