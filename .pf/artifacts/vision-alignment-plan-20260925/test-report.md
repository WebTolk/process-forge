## Test plan

Проверить целостность локальных ссылок, восемь уникальных карточек,
обязательные поля, соответствие списка плану, известные зависимости и
отсутствие циклов; разобрать JSON evidence и проверить доступность файлов.
Проверить git diff --check, отсутствие изменений продуктовых файлов и
единственное ручное изменение manifest. Смысловое review отдельно от автоматики.

- DOC-02: ровно T00–T07 без повторов; карточки содержат priority, complexity,
  dependencies, scope, work, acceptance, artifacts.
- DOC-03: таблица плана содержит те же восемь ID; зависимости имеют известные
  targets, совпадают с ожидаемым графом и не содержат циклов.
- DOC-04: JSON evidence корректен; каждый path существует.
- DOC-05: git diff --check проходит; изменения src/tools/schemas/templates/docs
  отсутствуют, включая index; manifest diff содержит только выбор процесса.
- DOC-06: ручная проверка охвата baseline и границ задачи — [review.md](review.md).
- GOV-01: PF принимает переходы только с evidence; финальный статус проверяется
  после evolve в Run. До этого не объявлять run_completed.
