Разрешённый installed target: D:\.agents\processforge. Обновление только по Core ownership manifest из проверенного чистого кандидата HEAD a180ad624442d4fbe8ac1710073ef7d4c44babc4. Штатные backup/journal сохраняются. Force локальных изменений не разрешён автоматически; конфликт требует отдельного решения. Текущий host-owned MCP не убивается: оператор перезапустит сессию после готовности handoff. Изменение файлов не равно обновлению уже загруженных модулей.
