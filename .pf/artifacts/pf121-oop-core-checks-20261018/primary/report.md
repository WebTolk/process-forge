# Пути выходов Work, обнаружение платформы, окружение и JSON Schema

Реализация завершена; итоговые исходники готовы к независимому ревью.
Baseline: `8b1b122ddaecb755c702f515eafbaf171ef1590f`.

Четыре собранных native-вклада создали `WorkOutputPolicy`,
`ProjectDetectionService`, `WorkerEnvironmentPolicy` и `UpdateSchemaChecks`.
Существующий `common.values` дополнен канонической `list_value`; весь прежний
файл сохранён побайтно. `ContextContractInputs` и определения драйверов не
изменены и переиспользованы. Все модули сохраняют future annotations.

Основной исполнитель удалил 19 определений монолита: 17 алгоритмов методов,
общую `list_value` и устаревшую обёртку `normalize_required_outputs`.
AST всех 884 оставшихся определений совпадает с baseline после ожидаемой
замены вызовов. Сигнатуры, defaults, тела 18 перенесённых алгоритмов,
исходные исключения, порядок проверок и чтения сохранены.

Мигрированы действующие вызовы в монолите, компиляторе контекста, Host и восьми
существующих smoke-файлах. AST всех десяти внешних модулей после нормализации
предусмотренных импортов и вызовов совпадает с исходным. Host импортирует
конкретных владельцев отложенно на прежних местах вызовов. Проверки доступа,
подлинности, provenance, попыток и содержания отчётов не перенесены и не ослаблены.
Готовность required outputs и optional capabilities, создание процессов,
состояние попыток, сбор и восстановление сохраняют прежних владельцев.

Временное сравнение прошло 242/242 случая, включая 43 исходных исключения и
18 фактических наборов аннотаций. Проверены порядок ошибок JSON Schema,
мутация списка checks, правила путей и waiver, рекурсивное преобразование,
синтетическое окружение, отсутствие наследуемых секретов в сохраняемых данных,
актуальное чтение схем и файлов, изменения с прежними размером/mtime,
прямой и скопированный Core без CLI/Host. Вклад environment дополнительно
содержит собственное ограниченное синтетическое сравнение ветвей nt/posix.

Все десять выбранных существующих smoke-проверок прошли на итоговом Python:
обход и data-driven классификация, секреты окружения, CLI audit, документация,
containment отчётов, worker governance, схемы/поиск обновлений и prepared
execution. Prepared execution проверяет реальный изолированный offline shell
attempt; это не квалификация установленного Runtime или подключённого хоста.
Два symlink-пробника недоступны на устройстве; их SKIP сохранены в receipt.
Проверка remediation knowledge builder с экспортом/упаковкой исключена;
мигрированный прямой вызов компилируется, алгоритм валидатора проверен отдельно.

После исходных прогонов исправлена одна устаревшая ссылка в русской справке;
повторён только существующий тест документации (1.1 секунды). Прежние receipts
сохранены локально; `documentation-delta.json` связывает оба хеша. Python не
менялся, остальные smoke-прогоны не повторялись.

EN/RU справка отражает реальных владельцев и остаточный legacy.
Inventory обновил только 14 существующих строк и добавил четыре; 1322 строки
и три известных посторонних расхождения сохранены. Все 19 продуктовых файлов
зафиксированы в `product-manifest.json`. Остальные рабочие изменения не затронуты.

Это приёмка среза исходников на контракте 1.2.0. Архив, установленный Core,
Runtime и реально подключённый хост отдельно не проверялись; эпики OOP открыты.
Проверки содержимого ZIP и широкие релизные прогоны исключены. Новые MCP-ресурсы
остаются будущей задачей. После принятого ревью требуется коммит точных путей,
push одного SHA в оба remote, readback, завершение шести Work и root doctor.
GitVerse использует существующий GITVERSE_TOKEN с отключённым credential helper.
