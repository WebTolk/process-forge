ProcessForge 1.2.0 makes everyday project work more responsive and easier to follow.

- Clearer installation and workflow guides, with Python dependencies, storage and memory planning in one place.
- More consistent instructions and diagrams for people and AI agents, including how to continue existing work safely.
- More reliable background status and recovery when work is interrupted or a worker needs attention.
- Project scratch stays in `.pf/tmp/`; configurable reminders help you review old files. PF does not delete them automatically.

Before upgrading, back up your workplace and project state and follow the
[upgrade guide](https://github.com/WebTolk/process-forge/blob/v1.2.0/docs/releases/1.2.0-migration.md).
Existing legacy journals need the separate migration described there; installing Core does not migrate or delete them.

Download the ZIP together with its manifest.
[Русская документация](https://github.com/WebTolk/process-forge/blob/v1.2.0/docs/ru/releases/1.2.0.md).
