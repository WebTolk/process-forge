# ProcessForge 1.3.0-beta2

Эта бета исправляет чтение контекста и каталога при наличии приватных YAML
процессов в `processes/user/` или `processes/custom/` установленного PF.
Определения остаются данными проекта или рабочего места и не входят в публичные
manifest и ZIP Core. Идентификаторы процессов и порядок разрешения сохранены.

Правило применяется только к чтению неопубликованных YAML/YML. Опубликованные
файлы по-прежнему читаются из принятого образа релиза. Код, запись, альтернативные
пути, ссылки и файлы, изменившиеся во время чтения, отклоняются.

Очистка собственных временных файлов и каталогов теперь сравнивает идентификаторы
в одном формате Python по закреплённому handle Windows. Это устраняет ложный
отказ о подмене объекта на Python 3.11 без обрезания ID или ослабления проверок
владения. Захват ввода воркера и прежний smoke диалога обращаются к актуальному
владельцу адаптера.

Это изолированный выпуск после beta1; остальные неподтверждённые изменения
разработки в него не включены. Целевые проверки исправления не означают общей
приёмки Core, POSIX, RC или стабильного релиза; стабильная версия остаётся 1.2.0.
