# Optional Software/Web Domain Pack

This directory is an example domain pack. It is not part of ProcessForge core,
is not installed by workplace initialization, and is not activated by project
onboarding.

It contains:

- an optional software-development process and prompt;
- software/web knowledge-package examples;
- a data-driven project-classifier example.

To use these resources, copy or import only the required files into a workplace
or project-owned resource root and register them explicitly. ProcessForge does
not infer or activate them from their presence in the release archive.
