# ProcessForge 1.0.2 Update Notes

ProcessForge 1.0.2 does not require project `.pf` migration.

The release simplifies update server definitions. New and refreshed update sites
should provide `manifest_url` and `changelog_url`; the manifest can be served
over HTTPS or read from a local file path for offline, staged, or private
installations.

After unpacking the new core, run the usual project refresh checks:

- `python <processforge-root>/bin/pf.py project-upgrade-check --project-root <project>`
- `python <processforge-root>/bin/pf.py project-context-refresh --project-root <project>`
- `python <processforge-root>/bin/pf.py project-context-check --project-root <project>`
- `python <processforge-root>/bin/pf.py doctor-project --project-root <project>`
