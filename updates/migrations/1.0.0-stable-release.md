# Migration: 1.0.0 Stable Release

ProcessForge 1.0.0 keeps the file-first linked workplace model. The
distribution can be replaced independently from project `.pf/` artifacts.

## Required Actions

- Replace the installed ProcessForge distribution with the validated 1.0.0
  archive.
- Keep the previous installed distribution available until validation passes.
- Update the workplace distribution registry to point at the 1.0.0 installation.
- Run `doctor-workplace` for the workplace.
- Run `project-context-refresh`, `project-context-check`, and `doctor-project`
  for linked projects that should use the new distribution.

## Project File Changes

No automatic project migration is required. Existing projects may keep their
current `.pf/` artifacts. Refreshing the project context is recommended so the
snapshot records the updated distribution state.

## Rollback

Repoint the workplace distribution registry to the previous ProcessForge
distribution directory, then rerun workplace and project doctor checks.
